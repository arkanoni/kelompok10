## SiTOKO

SiTOKO atau Sistem Informasi Manajemen Toko adalah website yang dibuat untuk membantu mengelola kegiatan toko, seperti mengatur data produk, kategori barang, stok, dan laporan penjualan. Dengan adanya sistem ini, pengelolaan toko menjadi lebih mudah, rapi, dan terorganisir sehingga pemilik toko dapat memantau barang dan penjualan dengan lebih praktis.

## Fitur

- Menampilkan dashboard utama setelah pengguna berhasil login.
- Registrasi, login, dan logout pengguna.
- Pengguna dapat mengakses halaman sesuai hak akses yang dimiliki.
- Menampilkan informasi ringkasan data produk dan kategori.
- Mengelola profil akun pengguna.

## Admin

- Mengelola akun pengguna, termasuk menambahkan, mengedit, dan menghapus akun.
- Mengelola kategori barang (CRUD kategori).
- Mengelola seluruh data produk, termasuk menambahkan, mengedit, dan menghapus produk.
- Memantau jumlah stok dan harga seluruh produk.
- Mengelola data pesanan, termasuk melihat, memproses, mengubah status, dan menghapus pesanan.
- Melihat laporan keseluruhan data produk dan rekapitulasi stok barang.
- Mencetak atau melakukan export laporan inventaris.

## Pegawai

- Melihat daftar kategori dan produk yang tersedia.
- Menambahkan data produk baru sesuai kategori.
- Mengedit informasi produk, seperti nama produk, kategori, harga, dan stok.
- Menghapus data produk.
- Memantau dan memperbarui jumlah stok barang.
- Melihat dan mengelola data pesanan.
- Melihat laporan data produk dan rekapitulasi stok barang.

## User (Pembeli)

- Melakukan registrasi, login, dan logout.
- Melihat daftar produk dan harga produk.
- Memfilter produk berdasarkan kategori.
- Melakukan pembelian produk.
- Melihat riwayat pesanan.
- Melihat informasi status pesanan.
